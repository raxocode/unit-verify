# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-10-23
### Added
- Core TypeScript unit conversion library with 51 canonical units across 10 dimensions.
- Explicit ambiguity detection (`ton`, `gallon`, `fl oz`) and dimensional validation.
- Node.js CLI with single conversion and memory-bounded streaming NDJSON batch conversion.
- Local MCP stdio adapter exposing four local tools for AI agents.
